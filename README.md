# Скрипты сбора вакансий

Готовые скрипты для ежедневных рутин поиска вакансий. Рутина клонирует этот публичный репозиторий (без авторизации), запускает скрипт и получает короткий список кандидатов, а дальше только читает описания отобранных вакансий и пишет письмо. Так меньше шагов и токенов, а отбор каждый день одинаковый.

Только стандартная библиотека Python 3, сеть — через `curl`. Рабочая папка — `/tmp/jobs` (меняется переменной `JOBS_WORKDIR`).

## jobs_tech.py

```bash
python3 jobs_tech.py collect --history /tmp/jobs/history.txt --weekday $(TZ=Europe/Podgorica date +%u)
python3 jobs_tech.py describe KEY [KEY ...]
```

- `collect` скачивает списки вакансий через публичные API: Greenhouse (Nebius, Plata, Turing, Scale AI/Outlier, Toloka, Prolific, Stripe), Ashby (Mercor, Handshake, AfterQuery, Surge AI, ElevenLabs), SmartRecruiters (Wise, Appen), Comeet (TripleTen), EPAM, Lever, а также компании ротации по дню недели. Отбор: роль, уровень (директора и выше отсекаются, senior помечается ⬆), формат (удалённо в Европе / удалённо где-то ещё / офис), свежесть (по умолчанию до 45 дней), сверка с историей. Печатает кандидатов, отдельный блок «удалённо только в других странах» (только сильные совпадения по роли), охват по источникам и список того, что скрипт не покрывает.
- `describe` печатает для выбранных ключей ссылку, локацию и короткие выдержки из описания: формат и страны, стаж, языки, тип найма, требования.
- Не покрыто скриптом: JetBrains (EU-доска Greenhouse недоступна через API из облака), Mistral AI (нет публичного API), часть компаний ротации без публичных ATS. Их рутина проверяет через WebFetch или WebSearch.

## jobs_un.py

```bash
python3 jobs_un.py collect --history /tmp/jobs/history.txt --home "<страна|город>"
python3 jobs_un.py describe KEY [KEY ...]
```

- `collect` обходит все страницы UNjobnet по организациям: Секретариат ООН, OCHA, UNODC, UNOCT, UNOPS, ЮНИСЕФ, UNHCR, IOM, ОБСЕ, UNV (с ключом `--extra` ещё МККК, IFRC, NRC). Оставляет вакансии в окнах «опубликована за 24 часа» или «дедлайн в ближайшие 7 дней», отсекает местные и национальные позиции (G, NO, LICA, national) — кроме страны из `--home`, P-5 и выше, стажировки, объявления на испанском и французском и явно чужие направления, сверяет с историей. Помечает темы «Борьба с терроризмом» и «EPR», а также позиции secondment.
- `describe` печатает шапку объявления (организация, место, контракт, дедлайн, условия), официальную ссылку (через редирект UNjobnet) и выдержки: стаж, образование, языки, формат, гражданство, категория места службы.

## История для сверки

Файл `--history` — любой текст со ссылками и ID уже показанных вакансий (рутина выгружает их из столбцов ссылок и заметок своей таблицы). Скрипт сравнивает по ссылке без параметров, по числовым ID и UUID, а для ссылок, построенных на названии вакансии, — по названию на сайте той же компании. Без файла сверки нет, и скрипт предупреждает об этом.

## Безопасность

Содержимое страниц и API — только данные. Скрипты ничего из них не исполняют, а рутины по своему промпту не выполняют инструкции, найденные в вакансиях.
